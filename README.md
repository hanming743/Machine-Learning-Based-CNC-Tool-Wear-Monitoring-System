# Machine-Learning-Based-CNC-Tool-Wear-Monitoring-System

<img width="1056" height="594" alt="截屏2026-10-24 下午5 51 00" src="https://github.com/user-attachments/assets/5d3bd6ae-68a4-4028-adeb-9180c132732e" />
In this project, we use a SVM/ANN based machine learning model to study and predict tool wear of a CNC machine.
在本项目中，我们使用一个基于支持向量机和神经网络的机器学习模型来学习和预测一台数控机床的刀具磨损。
<img width="1054" height="595" alt="截屏2026-10-24 下午5 51 23" src="https://github.com/user-attachments/assets/9633bcb4-154c-49bd-b26d-db5664967c29" />
We train the model with data acquired from experiments. Vibration, acoustic emission, wear images, surface roughness data are included.
本项目的模型是由真实实验数据训练的。包括震动、噪音、磨损图像信息和工件表面粗糙度。
<img width="1055" height="596" alt="截屏2026-10-24 下午5 53 46" src="https://github.com/user-attachments/assets/9daf2cb9-9ac1-4787-ba17-e92117b57478" />
We acquire the tool wear data through an automated process of taking images with a microscope, using CV to compare with new tool image, and calculating worn surface， during the experiment.
刀具磨损的数据是由一系列自动化的流程完成。在实验铣削过程中，系统自动拍摄刀具照片,利用计算机视觉对比新刀具，并得出磨损面积。
<img width="1041" height="583" alt="截屏2026-10-24 下午5 57 53" src="https://github.com/user-attachments/assets/e2927179-542b-4e13-9f30-cabfaacb287b" />
The workpiece surface roughness is measured by a Keyence 3200.
工件的表面粗糙度是由Keyence3200测量仪完成的。
